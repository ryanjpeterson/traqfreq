# Progress deck: traqfreq build phases

A copy of the Slides artifact "traqfreq: build phases" (https://claude.ai/artifact/4xm8KY4kxsi36oa9gEToMe, private), kept in the repo so the build's progress travels with the code.

- `deck.json` (slide order, sections, fonts), `deck.css` (the shared look) and `slides/<id>.html` (one slide each, speaker notes in its `<aside>`) are the artifact's own files, copied unchanged.
- `index.html` is generated by `node scripts/build-deck.mjs`: every slide in order on one page, with its notes below it. Open it in a browser; don't edit it.

The artifact is the source. At the end of every session (CLAUDE.md, Session protocol) the deck is updated there, then copied here and `index.html` rebuilt, in the same commit as HANDOFF and CHANGELOG.
