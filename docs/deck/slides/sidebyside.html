TRAQFREQ · PORT 4492 · NEW REPO

Reads jimbo-dj, writes only its own

  • Opens jimbodj.sqlite as legacy, read-only
  • Its own library.sqlite, one cut-over at a time (P6)
  • Reuses jimbo-dj’s functions, vendored unchanged
  • Same Tailscale, same Plex

1

One writer at a time. When a module cuts over (P6), traqfreq takes that write and jimbo-dj’s switch for it goes off in the same release.

traqfreq · build phases

Nothing in jimbo-dj changes for this build until a cut-over. traqfreq opens jimbo-dj’s database read-only through a read-only mount, so it can’t corrupt it, and it reuses jimbo-dj’s Python by vendoring its functions unchanged, each with the commit it came from (jimbo-dj’s repo is private).
